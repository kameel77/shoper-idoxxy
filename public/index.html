Jak działa integracja?

Połączenie wykorzystuje OAuth2 oraz klucz API iDoxxy do bezpiecznej komunikacji. Wtyczka pobiera z iDoxxy zdefiniowane przez Ciebie grupy odbiorców i dokumenty, a następnie pozwala mapować zdarzenia w Shoperze (np. rejestrację konta, złożenie zamówienia) na odpowiednie grupy i dokumenty trwałego nośnika.

  • Automatyczna rejestracja oraz aktualizacja klientów w iDoxxy.
  • Przypisywanie klientów do grup na podstawie reguł zdefiniowanych w panelu wtyczki.
  • Wysyłka dokumentów (regulaminy, OWU) w formie trwałego nośnika z dowodem doręczenia.
  • Podgląd logów i diagnostyka komunikacji z API iDoxxy.

Kroki konfiguracji

  1. Pobierz token autoryzacyjny API z panelu iDoxxy.
  2. W wtyczce (zakładka Połączenie API) zapisz token autoryzacyjny API i wykonaj test łączności.
  3. Zsynchronizuj listę grup i dokumentów, aby były dostępne w mapowaniach.
  4. Skonfiguruj reguły przypisujące zdarzenia Shoper do grup iDoxxy oraz dokumentów.
